# GTA VI Style — THE MARISOL

The Marisol is served at `/gta-vi`. The default `/` route is the separate Cyberpunk / Neon Oasis experience. Both pages load the same single-page application shell, JavaScript, API client, translations, account/session logic, and backend endpoints; they are not reduced or duplicated apps.

The Marisol uses original local Miami-sunset room illustrations and a warm palette (hot pink, coral, tangerine, deep purple, midnight teal, off-white and ink). It uses Anton/Bebas Neue display type and Inter body type, a glass booking widget, room-type filters, original illustrated room cards, a three-stage booking sequence, and a neon postcard/check-in pass confirmation. It does not use Rockstar logos, game screenshots or copyrighted promotional art.

The header selector switches to Cyberpunk or GTA VI Style. The separate **After Dark** button appears only on The Marisol and can be switched ON/OFF independently; its preference is stored in the browser.

Both experiences use all of the same features: guest registration/login, account profile and password management, room search, guest-count capacity filtering, flexible-date price calendar, booking and confirmation, loyalty/Platinum discounts, My Reservations, cancellation, reviews, QR check-in, and all role-protected front-desk and manager tools (reservations, calendar, floor map, housekeeping, maintenance, email outbox, dashboard, audit history, CSV export and pricing). Payments are simulated in this prototype; no live gateway is connected.
